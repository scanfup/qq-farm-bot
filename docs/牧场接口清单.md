# 牧场接口清单与共用层调查

采样时间：2026-11-19T15:20:45.134Z；CDP 上下文：3。来源是当前已登录游戏的 SystemJS 原生 protobuf service stub、实际编码器字段标签、客户端配置，以及经现有 Bridge 发往原游戏服务器的只读请求。

本轮先完成接口发现和只读连通验证；没有接入牧场 Web 操作按钮，没有调用购买、投放、收取、喂养、放生、清理、放蚊子或场景切换/拜访写请求。表中“已实测”只适用于列明的只读 RPC；其余为当前客户端真实定义，不表示服务器写操作已验证。

### 目标结构与重要区别

- **animalpb.PlaceAnimalItem**：1: ranch_inst_id (int64)<br>2: animal_id (int64)<br>3: giant_cub_item_id (int64)
- **animalpb.AnimalRef**：1: ranch_inst_id (int64)<br>2: animal_inst_id (int32)
- **animalpb.ShelfRef**：1: ranch_inst_id (int64)<br>2: slot_index (int32)
- **animalpb.RanchDetail**：1: ranch_inst_id (int64)<br>2: capacity (int32)<br>3: animal_count (int32)<br>4: animals[] (animalpb.AnimalDetail)<br>5: grass (animalpb.GrassInfo)<br>6: husbandry_type (int32)<br>7: shelves[] (animalpb.ShelfDetail)<br>8: hazards[] (animalpb.RanchHazardView)
- **animalpb.AnimalDetail**：1: ranch_inst_id (int64)<br>2: slot_index (int32)<br>3: animal_inst_id (int32)<br>4: animal_id (int64)<br>5: stage (int32)<br>6: produce_count (int32)<br>7: can_harvest (bool)<br>10: grow_ready_at_ms (int64)<br>11: produce_ready_at_ms (int64)<br>12: grass_blocked (bool)<br>14: infant_ready_at_ms (int64)<br>15: producing (bool)<br>16: can_deliver (bool)<br>17: delivering_until_ms (int64)<br>18: can_feed (bool)<br>19: limited_can_used (bool)<br>20: can_donate (bool)<br>21: expected_harvest_exp (int64)<br>22: expected_harvest_sells[] (unknown)<br>23: expected_produce_exp (int64)<br>24: expected_produce_sells[] (unknown)<br>25: mature_ready_at_ms (int64)<br>30: mutation (animalpb.AnimalMutationView)
- **animalpb.ShelfDetail**：1: slot_index (int32)<br>2: lots[] (animalpb.ProductLotDetail)<br>3: total_remain (int64)<br>4: can_collect (bool)<br>5: can_steal (bool)
- **animalpb.ProductLotDetail**：1: item_id (int64)<br>2: base_num (int64)<br>3: remain_num (int64)<br>4: stolen_num (int64)<br>5: animal_id (int64)<br>6: can_steal (bool)<br>7: stealers[] (int64)
- **animalpb.RanchOpTimesView**：1: op_id (int64)<br>2: times_limit (int64)<br>3: used_times (int64)<br>4: remaining_times (int64)

- ranch_inst_id 是栏舍实例，animal_inst_id 是某一只动物实例，animal_id 是物种/配置ID；这些与商店 goods_id、幼崽 item_id 必须分开。AnimalRef/ShelfRef 的实际字段以上表导出为准。
- PlaceAnimal、FeedAnimal、HarvestRanch、DonateAnimal 请求没有 host_gid；不能把好友详情中的“可喂养”等状态直接当作允许对该好友执行这些自家操作。
- TriggerProduce、StealProduce、CleanRanch/CleanAllRanch、PutHazard、StrokeAnimal 有好友 host_gid。接生与成熟收取分别是 TriggerProduce、HarvestRanch；最终奖励、权限和冷却尚未执行验证。
- DonateAnimal 对应配置操作11008“放生未成熟动物”；不能因为客户端类名有 SellAnimal，就把它当作普通出售/收取。

### 共用层应怎样抽

1. **SceneContext**：统一GlobalSceneId。1是OLD_FARM，2是BIG_FARM（当前牧场/家园环境）。PlayerSceneLogin/SetDefaultScene是改变场景/偏好的操作，本轮未调用。
2. **FriendDirectory**：共用GetAll客户端、身份核对、好友关系；请求明确带global_scene_id，缓存按sceneId划分。农场plant字段9与新场景big_farm_status字段23是不同摘要，不能继续用“缺plant摘要就是自己/不可访问”套在牧场。
3. **VisitSession**：共用串行访问锁、activeGid/hostType/sceneId与finally退出、断线恢复；入口支持Enter/Leave和EnterHomestead/LeaveHomestead两套策略，不把host_type当场景ID。HostType当前REAL=0、BOT=1、HUMANOID=3。新家园EnterHomesteadReply含homestead_cells，旧EnterReply含lands。本轮没有调用牧场EnterHomestead，客户端切场景后实际写流程的reason/host_type仍需按真实调用核对。
4. **Inventory/ShopClient**：共用背包、商品读取、购买校验和价格刷新；按商品类型分派入栏/添加牧草机，避免重复购买与重复PlaceAnimal。
5. **FarmAdapter / PastureAdapter**：业务保持分开，前者Land/Plant/Farming，后者Ranch/Animal/Shelf/Hazard；不要把牧场货架实例当农场land_id。原串行队列、commandId幂等、uncertain锁继续共用。

场景2好友摘要字段：

1: can_steal (bool)<br>2: can_midwife (bool)<br>3: can_help (bool)<br>4: steal_lot_count (int32)<br>5: midwife_count (int32)<br>6: help_count (int32)

摘要只能用于候选展示/筛选；下发动作前仍读取牧场详情和服务端额度。当前实测证明直接GetRanchDetail(host_gid=好友)可读，不需要为了预览先发送旧农场Enter。好友接生、偷取、清理、抚摸、放蚊子虽有目标字段，写入权限/业务码/实际会话要求本轮未试。
